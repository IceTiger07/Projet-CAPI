---

Aide-mémoire (cours « Cas d'utilisation et expression des besoins ») :

- une étape = sujet + verbe + complément, qui fait avancer le scénario ;
- l'intention de l'acteur, pas le geste d'interface (« choisit la règle », pas « clique sur la liste déroulante ») ;
- pas de « si » ni de boucle dans le scénario nominal : les alternatives vont dans les extensions ;
- une extension commence par une **condition que le système peut détecter**.
